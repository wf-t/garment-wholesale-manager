# 操作指南

## 首次使用

运行自行构建的程序，或由项目维护者提供的可信发布包。程序在当前用户本地应用数据目录创建数据库。当前初始化流程不自动载入演示业务数据。

先维护仓库、分类、颜色、商品款号及颜色尺码 SKU，再添加客户并进行入库。

## 库存

- 到货入库：选择仓库和 SKU，登记数量与备注；系统记录库存流水。
- 盘点调整：填写盘点后的实际数量，系统按差额调整库存。
- 查询时区分实际、锁定与可用库存；销售审核后库存被预占，未发货前实际库存不变。

当前到货入库不等于完整的供应商采购单流程。

## 销售与配货

1. 选择客户、仓库和款号，在颜色尺码矩阵输入数量。
2. 核对售价、运费、优惠及收款状态；草稿可保存恢复。
3. 审核并锁库。可用库存不足或未收款订单超出有效信用额度时会被拒绝。
4. 开始配货，核对商品后完成配货，使订单进入待发货状态。
5. 整单发货，按需填写快递单号。系统扣减实际库存、释放预占并生成发货记录。
6. 客户收到货后确认签收。

当前支持整单发货，拆单发货和退换货需后续实现。

## 应收与收款

未收款订单发货后生成应收；已收款订单不重复挂账。在客户应收页面登记收款金额、日期、方式与备注。

收款必须大于零且不能超过该客户当前欠款。系统按最早欠款优先展示抵扣结果，可查看客户对账和导出应收汇总 CSV；客户档案也支持 CSV 导出。

## 数据位置与备份

数据库位置由以下规则生成：

```text
Environment.SpecialFolder.LocalApplicationData
└── ShanquanInventory/
    ├── data/main.db
    ├── backups/
    └── logs/
```

Windows 常见根目录为 `%LOCALAPPDATA%`；其他系统由 .NET 解析，排查时以 `AppPaths` 返回的实际路径为准。

当前未提供自动备份。手动备份时：

1. 完全退出程序及其他使用该数据库的进程。
2. 将整个 `data` 目录复制到带日期的备份目录，连同仍存在的 `main.db-wal` 和 `main.db-shm` 文件保存。
3. 恢复前先备份当前数据，退出程序后还原完整目录，再启动检查客户、库存和欠款。

不要在程序运行时只复制主数据库文件；不要将同一数据库放到网络共享盘供多台电脑同时操作。升级前保留可恢复的数据副本。
